Building Your First REST API in Go: From Scratch to Production

Published on April 14, 2023 · 5 min read · 3,120 views

Go (or Golang) has taken the backend engineering world by storm due to its execution speed, simple syntax, and native support for concurrency via goroutines. Unlike other languages that require massive web frameworks, Go's standard library includes almost everything you need to build production-grade REST APIs.

In this post, we will walk through setting up a simple, high-performance API server using Go's built-in net/http package, connecting to database services, and handling JSON serialization.

1. The Simple Server Structure

We can initialize an API endpoint in just a few lines of code: 

package main

import (
    "fmt"
    "net/http"
)

func helloHandler(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintf(w, "Hello, World!")
}

func main() {
    http.HandleFunc("/hello", helloHandler)
    http.ListenAndServe(":8080", nil)
}

This compiles into a single, dependency-free binary that boots up instantly and uses only a few megabytes of memory.

2. Parsing JSON Structs

Go uses struct tags to map JSON keys directly to typed fields. Here is how to create a handler that decodes requests and writes JSON responses: 

type Product struct {
    ID    string  `json:"id"`
    Name  string  `json:"name"`
    Price float64 `json:"price"`
}

func createProductHandler(w http.ResponseWriter, r *http.Request) {
    var p Product
    err := json.NewDecoder(r.Body).Decode(&p)
    if err != nil {
        http.Error(w, err.Error(), http.StatusBadRequest)
        return
    }
    
    w.Header().Set("Content-Type", "application/json")
    w.WriteHeader(http.StatusCreated)
    json.NewEncoder(w).Encode(p)
}

By leveraging Go's strong typing and fast compiler execution, you can build extremely scalable microservices capable of handling thousands of requests per second out-of-the-box.
